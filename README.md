# CS 340 – Client/Server Development

## Project Reflection

### How do you write programs that are maintainable, readable, and adaptable?

So, when writing programs I try to keep my code organized and easy to understand so that I can make changes without having to redo everything. One example from this course was creating the CRUD Python module in Project One and then reusing it for the dashboard in Project Two. Having the database operations in a separate module made things easier because I didn't have to rewrite the same code every time I needed to access MongoDB. It also made troubleshooting easier since I could work on the database connection separately from the dashboard.

### How do you approach a problem as a computer scientist?

I usually start by breaking down the requirements and figuring out what needs to be done before jumping into coding. For the Grazioso Salvare project, I had to understand what information the company needed and how to make that information accessible through a dashboard. I started by working with the MongoDB database, then developed the CRUD module, and finally connected everything to the dashboard. This project was different from some of my previous assignments because I had to bring multiple components together instead of focusing on one program or function. In the future, I would continue breaking projects into smaller steps, testing each part as I go, and making sure the final product meets the client's needs.

### What do computer scientists do, and why does it matter?

Computer scientists develop solutions that help people and organizations solve problems, manage information, and work more efficiently. In this project, the dashboard helps Grazioso Salvare search through animal shelter records and identify dogs that might be suitable for search-and-rescue training. Instead of manually searching through a large amount of data, users can filter the results and view information through an interactive dashboard. Projects like this show how software and databases can make everyday tasks easier while helping organizations make better decisions.
